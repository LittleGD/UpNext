# 가방 개선과 XP 밸런스 통합 리뷰

기준: 2026-09-06, main `c351519`, 가방 개선 `24b1693`.

## 최종 변경

가방의 아이템 상세, 장착 전후 비교, 연결 조건 안내, 배치 추천, 장착·해제와 회전 수정에 XP 밸런스를 통합했다. 가방 설계와 Android·iOS 조작 검증은 [가방 시스템 조사와 개선](research-and-changes.md)에 정리했다.

| 보상 | 이전 | 변경 후 |
| --- | --- | --- |
| 카드매치 중복 카드 기본 XP | 일반 10, 희귀 25, 유니크 50, 전설 100 | 3, 8, 15, 30 |
| 카드매치 중복 카드 런 XP | 버프 적용 후 별도 상한 없음 | 버프 포함 최대 100 |
| 던전 미니게임 성공 기본 XP | 45~90 | 18~36, 기존의 40% |
| 방치 XP | 분당 0.5 | 분당 0.25 |

새 카드는 수집 보상을 제공하며 중복 카드 XP를 함께 주지 않는다. iOS에서 결과 표시와 실제 수령이 서로 다른 식을 사용하던 문제를 수정했다. 이제 매치 토스트, 결과 XP, 실제 수령이 같은 계산을 사용한다. 받기와 중도 종료는 한 번만 보상을 지급한다.

기존 경험치와 레벨, 레벨업 경계, 챌린지 완료 XP, 코인, 방치 8시간 상한과 최소 5분 대기는 유지한다. 카드매치의 기존 플랫폼별 버프와 카드 선택 방식은 유지했다. 웹은 Double Loot가 추가 카드 1장, iOS는 XP 2배이므로 모든 카드매치 조합이 플랫폼 간 같은 지급액을 갖는다는 뜻은 아니다. 기본 XP 표와 런 상한을 양쪽에 적용했다.

## 통합 중 확인한 문제

밸런스 작업은 main보다 오래된 브랜치에서 진행되어 최신 챌린지 보상 결과와 미니게임 대기 상태 처리에 충돌이 있었다. 최신 main의 처리를 보존하면서 새 XP 규칙을 적용했다. iOS Flavor.json은 이전 파일 전체를 복사하지 않고 통합된 웹 데이터에서 다시 생성했다. HEAD와 의미 단위로 비교한 변경은 미니게임 성공 XP 30곳뿐이다.

최신 main에는 던전의 층과 NG+에 따른 보상 배율이 있다. 기본 XP 18~36은 최종 지급액의 상한이 아니다. 예를 들어 기본 65 XP가 26 XP로 줄면 1층 실제 지급은 113에서 45로 줄어든다. 이 배율을 제거하면 기존 고층 진행을 바꾸므로 유지했다.

처음 통합한 테스트는 기본 XP를 최종 지급액으로 간주해 실패했다. 30개 이벤트 각각을 1층, 50층, 50층 NG+ 2에서 실행하도록 보강했다. 보상이 기존의 약 40%인지, 배율이 한 번만 적용되는지, 결과 표시와 지급액이 같은지, 재호출로 XP가 중복 지급되지 않는지 확인했다. 실패 시 성공 XP를 받지 않는 것도 확인했다.

## 통합 검증

- 웹 전체: 56개 파일, 956개 테스트 통과.
- iOS 통합: 가방 모델 39개, 가방 스토어 17개, XP 보상 6개, 가방 UI 7개, 카드매치 UI 1개, 총 70개 테스트 통과. iPhone 17, iOS 26.2 시뮬레이터와 Xcode 26.6에서 실행했다.
- iOS UI에서 실제 장착·해제 후 회전, 상세 열기, 연결 안내, 영어 최대 확장, 100 XP 표시와 수령을 실행하고 스크린샷을 확인했다.
- 웹 TypeScript, 변경 파일 ESLint, 프로덕션 webpack 빌드 통과.
- 웹·Swift 계산 비교: 방치 10행, 게임 규칙 23행, 전투 228행, 가방 168행, 총 429행 일치.
- 번역 placeholder: 4개 언어 × 2,630개 키 통과. main 대비 iOS 기존 키 삭제 0개, 기존 값 변경 0개, 가방 안내 키 36개 추가.

검증은 로컬 빌드와 시뮬레이터에서 수행했다. 플레이 시간에 따른 실제 성장 속도와 가방의 이해도·재미는 출시 후 사용자 피드백으로 확인할 항목이다.
