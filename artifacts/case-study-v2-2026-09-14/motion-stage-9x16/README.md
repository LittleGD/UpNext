# UpNext 모션 데모 9:16 v3 (레퍼런스 2 문법 + 픽셀 레트로, 2026-09-14)

1080×1920, 30fps, 16초. 다크 유지, 카피 유지("Draw Today / Your ✳ Challenge", 보조 "Keep the Flame", "Grow your Hero").

v2에서 고친 것
- 화면 소재를 전부 원본 해상도(1206×2622)로 교체. 반해상도 클립에서 고른 시각을 `map_frames.py`로 원본 녹화 시간에 되돌려 뽑았다.
- 텍스트 잘림: 렌더 전에 샘플 시각 18곳에서 보이는 텍스트의 박스가 안전 영역(가로 40~1040, 세로 60~1860) 안에 있는지 검사한다(`OVERFLOW` 로그). v3는 경고 0건.
- 폰 목업: CSS 3D 베젤에 두께 슬라이스 8장, 광택, 그림자. rotateY 8~14°에서 옆면이 보인다. 실제 3D 에셋은 아님.
- 통통 튐: 등장은 스프링 곡선(cubic-bezier(.34,1.56,.64,1))으로 오버슈트, 마스코트와 부품은 스쿼시·스트레치.
- 픽셀 레트로: 블록 전환마다 6단계 계단 와이프, 픽셀 아이콘(pixelarticons, MIT) 스파클이 4단계 스텝으로 팝, 헤드라인 픽셀 그림자, 스캔라인 오버레이, 앱 로고 마크와 던전 영웅 스프라이트를 마스코트로 사용.

샷 순서는 16:9와 같고 세로 구도로 재배치했다. 렌더는 16:9 README와 같은 방식이며 `render3.js`, `STAGE=stage3.html`.

더 올리려면
- 실제 3D 목업: GLB 폰 모델을 three.js로 올려 화면 텍스처를 입히면 반사와 두께가 진짜가 된다. 모델은 인터넷에서 받아야 하므로 파일명·출처·라이선스를 정한 뒤 진행.
- After Effects: 이 타임라인(박자 그리드, 샷별 포즈, 부품 좌표)을 그대로 컴포지션으로 옮겨 마무리를 손으로 하는 용도로 적합. 처음부터 AE에서 만드는 것보다 코드 쪽이 빠르다.

## 레퍼런스 2 정밀 재분석 (프레임 단위, 2026-09-14 저녁)

측정 방법: 24fps 379프레임을 90×160 회색조로 줄여 인접 프레임 차이(평균 절대값)를 구했다. 값이 크면 그 순간 화면이 많이 움직인 것이다. 컷은 50~230, 컷 안의 움직임은 중앙값 4.4, 상위 10%가 14.8.

프레임 스트립으로 확인한 것
- 알림 컷: 폰이 컷 안에서 계속 천천히 기울어지고, 알림 카드는 폰 밖에서 살짝 회전하며 떠 있다.
- 잔액 컷: £0→£5,428 카운트업이 폰 회전과 동시에 진행되고, 다음 컷은 검정 배경에서 폰이 4프레임 만에 작아지며 퇴장한다.
- 로고 컷: 돼지가 1~2프레임 단위로 꿈틀거리는 루프. 페이드는 한 번도 없다.

우리 v3가 엉성했던 원인
1. 등장이 페이드+이동이라 둥둥 뜬다. 레퍼런스는 페이드가 없다.
2. 정착이 0.5초로 느리다. 레퍼런스는 6~8프레임(0.25~0.33초).
3. 퇴장이 없다. 레퍼런스는 컷 직전 8~10프레임 가속으로 컷을 액션 위에 얹는다.
4. 홀드가 선형 드리프트라 기계적이다. 레퍼런스는 감속하는 느린 회전이다.
5. 부품이 튀어나온 뒤 죽어 있다. 레퍼런스는 떠서 미세하게 회전한다.

v4 모션 규칙(12원칙 대응)
- 슬로우 아웃: 등장 6~9프레임 outExpo 또는 outBack, 페이드 없음.
- 무빙 홀드: 컷 안에서 rotateY 4~5° 감속 드리프트.
- 슬로우 인: 퇴장 7~8프레임 inCubic으로 화면 밖 또는 카메라 쪽으로 가속.
- 예비 동작과 부차 동작: 부품이 튀어나오기 3프레임 전 폰이 2.5° 반동, 튀어나온 뒤 부품은 ±6px 부유와 ±1.5° 회전.
- 스쿼시·스트레치: 헤드라인 착지 2프레임 1.1/0.9, 마스코트 6포즈.
- 아크: 부품은 x·y·z를 서로 다른 오버슈트 곡선으로 움직여 직선이 아닌 궤적.
- 타이밍과 과장: 착지 오버슈트 6~8%, 마스코트는 25%.
- 스텝: 마스코트와 스파클은 3~4프레임 홀드의 on-fours.
- 팔로우 스루: 헤드라인 2행은 2프레임 지연, 스파클은 팝 3프레임 뒤.
- 스테이징: 컷마다 초점 하나(폰 또는 부품), 나머지는 배경 블록.
