# 리텐션 안내 디자인 수정

2026-09-09. 기존 UpNext UI를 기준으로 알림과 위젯 안내를 다시 구성했다. 빌드 32에 포함할 수정과 검증 결과다. 앞서 제출한 빌드 31의 출시 기록과 구분한다.

## 적용 기준

- 기존 `ReviewPromptModal`, `FortunePromptModal`, `Typography`, `UNButtonStyle`, 웹의 공통 타이포그래피와 색상 토큰을 확인했다.
- iOS의 큰 시트를 기존 중앙 모달로 변경했다. 카드 너비 최대 380pt, 안쪽 여백 20pt, 모서리 18pt를 적용했다.
- 기존 서체, 픽셀 아이콘, 라임색 CTA를 사용한다. 기본 버튼 52pt, 보조 버튼 48pt, 시간 선택 44pt의 터치 영역을 유지했다.
- 긴 소개와 중복 설명을 제거하고 단계마다 짧은 제목, 필요한 한 문장, 직접 조작하는 미리보기를 남겼다.
- 알림은 시간 선택 후 실제 권한과 예약을 확인한다. 위젯은 길게 누르기, 크기 선택, 배치를 연습한다. Android는 이후 시스템 추가 창으로 직접 이어진다.
- iOS는 홈 화면에서 실제 추가하는 순서를 안내하고, 복귀 후 설치 여부를 확인한다. 연습만으로 설치 완료를 표시하지 않는다.

## 검증

- 웹 프로덕션 빌드 통과 (`next build --webpack`). 검증용 페이지가 최종 라우트에 포함되지 않음을 확인했다.
- Android 디버그 APK 빌드 통과.
- 웹 리텐션 테스트: 3개 파일, 9개 테스트 통과.
- TypeScript, 변경 파일 ESLint, 4개 언어 카탈로그, 픽셀 아이콘, 사용자 카피 검사 통과.
- iOS 리텐션 단위 테스트 6개, UI 테스트 5개 통과. 알림 거절 후 설정 복구, 첫·두 번째 챌린지, 건너뛰기, 영어·동작 줄이기, 실제 위젯 설치를 포함한다.
- iPhone SE 3세대에서 한국어 전체 흐름과 영어·동작 줄이기 테스트 2개 통과. 카드와 버튼이 화면에 들어오는지 캡처를 확인했다.
- 최종 스타일을 적용한 iPhone 17에서 전체 흐름 1개를 다시 실행해 통과했다. 최초 시도에서는 테스트 복사본의 Firebase 설정 누락과 이전 테스트에서 설치한 위젯 때문에 실패했다. 설정 파일을 복원하고 전용 시뮬레이터를 초기화한 뒤 재검증했다.
- Android API 36 에뮬레이터에서 실제 알림 예약, 길게 누르기, 크기 전환, 배치, 시스템 위젯 추가와 앱 복귀 후 설치 확인까지 통과했다.
- Android 개발용 캐시를 갱신한 뒤 기존 브랜드 서체가 로드된 화면을 다시 캡처했다. 앱 전체의 기존 폰트 로딩 정책은 변경하지 않았다.
- 검증용 페이지와 로컬 서버 주소, 임시 Android 디버그 설정을 제거했다. 네이티브 생성 설정이 원래 프로덕션 주소로 복원됐음을 확인했다.

## 빌드 32 효과음 복귀 수정

- iOS: 중단 종료 알림이 누락되어도 앱 복귀 시 오디오 세션을 다시 활성화한다. 미디어 서비스 재설정도 복구하며 음소거 설정을 유지한다.
- Android: WebView의 `document.hidden`이 홈 이동 후에도 false인 경우를 확인했다. 기존 Capacitor App 플러그인의 pause와 appStateChange를 연결했다.
- iOS 효과음 테스트 6개와 리텐션 단위 테스트 6개 통과. 중단 종료 알림 누락, 미디어 서비스 재설정, 음소거, 배경 재생 중단을 포함한다.
- Android API 36의 실제 앱 WebView에 현재 믹서와 동일한 생명주기 이벤트 연결을 주입하여 홈 이동과 복귀 3회 후 재생, 음소거 유지 확인. React 연결은 별도 회귀 테스트로 검증했다.
- 웹 전체 테스트 1,019개 통과 후 Android 연결 회귀 테스트를 추가했다. 추가 후 효과음 관련 15개 테스트 통과.
- 기본 알림 안내의 불필요한 부제와 번역을 삭제했다. `ios-reminder.png`는 삭제 후 캡처이며 기존 Android 알림 캡처는 삭제 전이다.
- iOS 초기 검증 실행이 테스트 호스트 연결 단계에서 지연되어 중단했다. 전용 시뮬레이터 초기화와 정상 로컬 서명으로 다시 실행했다. Android는 iCloud의 빌드 중복 파일 읽기에 멈춰 /tmp 빌드 복사본으로 검증했다.

- 빌드 32 최종 iOS 검증: 효과음 6개, 리텐션 단위 6개, UI 5개, 총 17개 통과. 실제 위젯 설치 후 앱 복귀 확인 화면을 `ios-build32-widget-confirmed.png`에 보관했다.
