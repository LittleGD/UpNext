# UpNext 부제(subtitle) 개선안 4개국어

부제는 30자 제한이며, 사용자에게 보이는 동시에 검색 색인 대상이다. 영향력은 앱 이름 다음으로 크다.
따라서 두 가지를 동시에 만족해야 한다: 사람이 읽고 설치하고 싶어질 것, 그리고 이름과 키워드가 못 덮는 검색어를 담을 것.

## 문제: 현재 부제가 이름의 단어를 그대로 반복한다

애플은 이름, 부제, 키워드를 함께 색인한다. 같은 단어를 두 곳에 넣으면 두 번 세지 않고 한쪽 자리만 버린다.

| 로케일 | 이름 | 현재 부제 | 반복된 단어 |
|---|---|---|---|
| ko | UpNext: 챌린지 카드 갓생 | 카드 뽑아 오늘의 챌린지, 게임처럼 갓생 | 카드, 챌린지, 갓생 (3개 전부) |
| ja | UpNext：チャレンジカード習慣化ゲーム | 毎日カードを引いて、ゲーム感覚で習慣化 | カード, ゲーム, 習慣化 |
| zh-Hans | UpNext：卡牌挑战·游戏化自律 | 每天抽卡做挑战，像游戏一样养成习惯 | 挑战, 游戏 |
| en-US | UpNext: Challenge Card Habits | Draw cards, level up your day | cards |

한국어가 가장 심하다. 부제 22자 중 실질 신규어는 "뽑아, 오늘의, 게임처럼" 뿐이고 나머지는 이름의 복사다.

## 개선안

원칙: 이름에 있는 단어도, 키워드 필드에 넣은 단어도 쓰지 않는다. 대신 앱의 실제 훅(매일 미션을 뽑고, 사진으로 인증하고, 캐릭터가 성장한다)을 문장으로 만든다.

### ko  (24자 / 30자)

```
매일 뽑는 미션, 사진으로 남기는 성장 기록
```

새로 확보하는 검색어: 매일, 미션, 사진, 성장, 기록
사람에게 주는 메시지: 매일 뽑는다는 리듬, 사진 인증, 성장의 축적. 이름의 "챌린지 카드 갓생"과 겹치지 않으면서 서로 보완된다.

### ja  (21자 / 30자)

```
毎日のミッションを写真で残してレベルアップ
```

새로 확보하는 검색어: 毎日, ミッション, 写真, レベルアップ
`記録` 은 키워드 필드에 이미 있어 의도적으로 뺐고, 대신 `残して` 로 같은 뜻을 전달한다.

### zh-Hans  (16자 / 30자)

```
每天抽任务，拍照记录你的成长升级
```

새로 확보하는 검색어: 每天, 任务, 拍照, 记录, 成长, 升级
현재 부제의 `抽卡` 는 이름의 `卡牌` 와 겹쳐 `抽任务` 로 바꿨다. 14자 여유가 남으므로 검색어를 더 넣을 수도 있으나, 중국어 부제는 짧고 리듬감 있는 편이 전환에 유리해 여백을 남겼다.

### en-US  (29자 / 30자)

```
Daily quests with photo proof
```

새로 확보하는 검색어: daily, quests, photo, proof
`level up` 은 현재 부제에 있으나 넣지 않았다. 30자 안에서 `daily`, `photo`, `proof` 셋을 살리는 편이 검색 가치가 크다고 판단했다. 로그라이크 톤을 살리려면 `Draw a quest, prove it, level up`(32자)이 좋지만 제한을 넘는다.

## 적용 시 유의점

부제 변경은 키워드와 마찬가지로 새 버전(1.0.1)이 심사를 통과해야 실제 스토어에 반영된다.

부제를 바꾸면 키워드 필드도 다시 봐야 한다. 부제에 넣은 단어(매일, 미션, 사진, 성장, 기록 등)는 키워드에서 빼야 자리가 낭비되지 않는다. 현재 키워드에는 이 단어들이 없으므로 지금 개선안 그대로는 충돌이 없다.

용어 선택은 각 문화권 습관 앱의 관행에 기반한 판단이며 실제 검색량 데이터에 근거하지 않았다. 확정 전 ASO 도구로 검색량과 난이도를 확인하면 더 좋다.
