# UpNext 1.0.1 (빌드 18) 릴리스 노트

App Store Connect 의 "이번 버전의 새로운 기능"(whatsNew) 에 로케일별로 붙여넣는다.
용어는 인앱 카탈로그와 일치시켰다: 아지트 = Hideout / アジト / 据点, 던전 = Dungeon / ダンジョン / 地牢, 카드팩 = Card Pack / カードパック / 卡包.

---

## ko

사진 촬영 안정성을 크게 개선했어요.

• 챌린지 인증 사진을 찍은 직후 화면이 검게 멈추던 문제를 해결했어요.
• 통화 수신이나 다른 앱의 카메라 사용으로 촬영이 끊긴 뒤에도 카메라가 정상으로 돌아옵니다.
• 셔터를 연달아 눌러도 꾸미기 화면이 멈추지 않아요.
• 사진 저장과 앨범 스크롤이 훨씬 가벼워졌어요.
• 앨범 폴라로이드에서 글자가 겹쳐 보이던 문제를 고쳤어요.
• 레벨업과 카드팩이 동시에 뜨며 순서가 엉키던 문제를 정리했어요.
• 아지트와 던전 화면의 번역 누락을 마무리했어요.

## en-US

This update makes photo capture much more reliable.

• Fixed a black screen that could freeze the app right after you took a challenge photo.
• The camera now recovers properly after an interruption, such as an incoming call or another app using the camera.
• Tapping the shutter repeatedly no longer leaves the decorating screen stuck.
• Saving photos and scrolling the album are noticeably lighter and faster.
• Fixed overlapping text on album polaroids.
• Fixed the ordering conflict when a level up and a Card Pack appeared at the same time.
• Completed missing translations on the Hideout and Dungeon screens.

## zh-Hans

本次更新大幅提升了拍照的稳定性。

• 修复了拍摄挑战照片后画面变黑并卡住的问题。
• 在来电或其他应用占用摄像头导致中断后，相机现在能够正常恢复。
• 连续点击快门不会再导致装饰界面卡住。
• 照片保存与相册滚动更加流畅、更省内存。
• 修复了相册拍立得上文字重叠的问题。
• 修复了升级与卡包同时出现时的顺序冲突。
• 补全了据点与地牢界面的缺失翻译。
