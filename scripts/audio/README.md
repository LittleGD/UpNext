# 앱 사운드 개선

2026-09-09, 웹과 네이티브 iOS에 적용한 로컬 구현.

음악 파일 자체에 끝과 시작의 크로스페이드를 넣었다. 기본값은 3초이며, 강철 산봉우리는 원곡의 165 BPM에 맞춰 두 마디(8박, 약 2.91초)를 겹친다. 끝과 시작을 겹친 뒤 재생 시작점을 옮겨 반복 경계가 원래 곡의 인접 샘플로 이어지도록 했다. 웹은 AAC 인코딩 패딩을 제외한 정확한 길이를 반복한다. 일반 화면 전환과 보스전 종료 후 복귀는 2.4초 크로스페이드다. 던전 음악의 믹서 음량은 42%, 보스 음악은 55%다. 파일의 기준 음량은 -20 LUFS로 맞췄다.

보스 여부는 전투 로그의 등장·조우·승리·종료 상태로 판단한다. 배너가 닫히거나 일시정지해도 보스 음악은 유지된다. 보스전이 끝나면 해당 던전 음악으로 돌아오고, 던전 화면을 나가면 공통 음악으로 돌아온다.

보스 전환음은 원본의 피치를 유지하면서 빠르게 압축하고 끝을 페이드아웃해 0.9초로 다듬었다. 전환음의 믹서 음량은 26%다. 전환음이 시작하면 기존 음악은 0.65초에 걸쳐 내려가고, 보스 음악은 전환음보다 0.45초 뒤에 시작한다. 웹은 두 파일의 로딩 순서가 뒤바뀌어도 이 순서를 지키며, 전환 중 화면 이동·음소거·백그라운드 전환은 남은 전환음을 취소한다.

강철 산봉우리는 사용자 요청에 따라 MintoDog의 [Mountain Stage](https://opengameart.org/content/mountain-stage)로 교체했다. 산악 액션 스테이지용 8비트 곡이며 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)으로 공개되어 있다. 가공 후 반복 길이는 약 55.27초다. 이제 강철 산봉우리 탐험과 보스전에서 서로 다른 곡이 재생된다. 제공받은 보스 음악과 다운로드 폴더의 원본은 유지한다.

## 효과음

기존 합성 SFX를 샘플 재생으로 교체했다. 63개 이름으로 기존 앱 효과음과 새 영웅 키우기 효과음을 연결한다. 두 플랫폼이 동일한 WAV 파일을 사용하며, 12개 효과음을 동시에 재생할 수 있다. UI 클릭과 일반 공격은 작게, 결과·희귀 보상·보스 등장은 더 분명하게 들리도록 음량을 나눴다. 짧은 시간에 같은 효과음이 반복될 때 중복 재생을 제한한다.

- 전투: 일반 공격, 피격, 치명타, 회피, 빗나감, 방어, 독, 회복, 직업별 스킬.
- 탐험: 조우, 층 이동, 선택지, 보물, 장비 드롭, 희귀 드롭, 승리, 쓰러짐, 시간 부족, 복귀.
- 성장: 장비 장착·판매, 강화 충전과 성공·유지·파괴, 스킬 학습, 전직, 레벨업, 수련 보상, 탐험 보상 수령.
- 미니게임 11종: 카드 뒤집기·매칭, 순서 시연·입력, 파이프 회전, 연타, 회피, 분류, 계산, 차이 찾기, 타이밍, 경로 통과와 결과.
- 룬 상자: 기존 상자 연출의 공개 시점에 보상 효과음을 재생한다. 강화 상위 단계의 성공·파괴 큐도 유지한다.

강화 결과와 룬 상자 결과를 연출 시작 시점에 소리로 미리 알려주지 않는다. 웹의 탐험 미니게임 상태에서도 던전 화면을 유지하도록 분기를 보완했다.

## 재생 수명과 설정

기존 사운드 설정을 음악과 효과음 모두에 적용한다. 햅틱 설정은 별도다. 웹은 첫 입력 이후 재생하며 숨겨진 탭에서는 두 소리 채널을 정지한다. iOS는 무음 스위치를 존중하는 ambient 세션을 사용하고 앱 비활성화·오디오 인터럽트에서 정지한다. 다시 활성화하면 현재 화면의 음악으로 복귀한다. 웹의 비동기 다운로드 완료가 음소거나 화면 이동 뒤에 지난 소리를 되살리지 않도록 취소 상태를 확인한다.

## 출처와 재생성

효과음은 Kenney의 다음 팩에서 선별했다. 각 팩의 CC0 라이선스 원문을 `public/audio/LICENSE-*.txt`와 iOS 번들에 포함했다. 파일별 원본 매핑과 음악 원본의 SHA-256은 `public/audio/manifest.json`에 있다. 강철 산봉우리의 작곡가, 원본 링크, 라이선스, 가공 내역은 `LICENSE-mountain-stage.txt`에도 기록했다.

- [Digital Audio](https://kenney.nl/assets/digital-audio)
- [Interface Sounds](https://kenney.nl/assets/interface-sounds)
- [Music Jingles, 8-Bit jingles](https://kenney.nl/assets/music-jingles)
- [RPG Audio](https://kenney.nl/assets/rpg-audio)
- [Casino Audio](https://kenney.nl/assets/casino-audio)

재생성에는 ffmpeg와 Python numpy가 필요하다. 강철 산봉우리는 저장소에 보관한 `scripts/audio/sources/mountain_stage_bpm165.ogg`를 사용하므로 다시 생성해도 예전 곡으로 돌아가지 않는다. 두 번째 인자는 위 팩을 `digital-audio/`, `interface-sounds/`, `music-jingles/`, `rpg-audio/`, `casino-audio/` 하위 폴더로 푼 디렉터리다.

```sh
python3 scripts/audio/prepare.py /path/to/original-mp3s /path/to/extracted-packs
```

웹 엔진은 `src/lib/audio.ts`, 게임 상태와 소리 매핑은 `src/lib/upHeroAudio.ts`, iOS 엔진은 `SoundPlayer.swift`, 게임 매핑은 `UpHeroAudio.swift`에 있다. 생성된 `audioCatalog.ts`와 `SoundName.swift`는 준비 스크립트로 함께 갱신한다.

## 검증

- 웹 전체 테스트: 25개 파일, 332개 테스트 통과.
- 오디오 회귀 테스트: 비동기 로딩 순서, 음소거 취소, 배경 복귀, 효과음 중첩, 보스 상태와 결과 매핑.
- Chromium 실제 Web Audio: 음악 10개·효과음 67개 디코딩, 각 음악의 반복 경계 렌더링, 전환 완료 후 음악 노드 1개, 음소거 후 두 채널 노드 0개 확인.
- 실제 웹 던전: F9 전투에서 공격·피격·치명타, F10 보스의 전환음과 BGM, 쓰러짐 효과음과 원래 던전 음악 복귀를 재생 호출 기록과 화면으로 확인. 페이지 실행 오류 0개.
- 강철 산봉우리 교체 후 Chromium 검증과 오디오 테스트 11개를 다시 통과했다. 새 음원과 보스 음원의 구분, 웹·iOS 파일 일치도 확인했다.
- iOS 시뮬레이터: 새 강철 산봉우리 음원을 포함한 전체 오디오 리소스 준비, 공통·강철 산봉우리 음악의 끝을 넘는 실제 반복, 보스 전환, 음소거, 배경 복귀, 상태 매핑 등 오디오 테스트 4개 통과.
- 보스 전환 조정 후 웹 오디오 테스트 14개와 실제 브라우저 검증을 통과했다. 전환음 길이 0.9초, 음량 26%, 음악과의 시작 간격 0.45초를 재생 기록으로 확인했다. iOS는 동일한 사운드 코드와 음원을 담은 검증용 복사본에서 오디오 테스트 4개를 통과했다. 초기 전체 앱 빌드는 동시 수정 중인 알림·위젯 설정 코드의 별도 오류로 막혀 해당 코드만 복사본에서 보완했다.
- `boss-transition-preview.m4a`는 실제 웹 믹서에서 녹음한 전환 미리듣기다.
- 실기기 스피커·이어폰에서의 청감 평가는 별도로 남아 있다.
